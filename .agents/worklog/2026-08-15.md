## 14:20 CST — S2 实现：流程 DAG + 控制流

- 变更：新增 `sohara-runtime` crate（`FlowGraph` 构建：路由/环检测/可达性告警；`Executor`：按记录图遍历 walk 模型 + 控制原语）。core 新增 `control.rs`（ControlNode/SwitchCase/JoinMode）与 `util::parse_duration`，`BuiltStep::Control`。config 的校验从「线性」升级为「DAG」（多 source 允许、环检测、端点校验、`when` 表达式解析），Step 新增 `when/on_error/retry` 字段；builtins 新增 switch/foreach/loop/parallel/join/delay/batch 工厂；CLI 切换到图执行器。
- 关键语义：控制步骤=运行时原语，循环体=下游子图迭代（主图保持 DAG）；`parallel` 以 correlation id 扇出、`join` 按 all/any/n 汇聚合并；`batch` 按 size 触发 + EOF 兜底，产出 `{items:[...]}`；`on_error: fail|continue|retry`（retry 带退避）。
- 过程中修复的真实缺陷：source 节点 walk 不转发路由（导致 0 输出）；`continue` 策略误入重试循环；隐式线性串联在 DAG 模型下丢失（无 edges 时按声明顺序补链，控制节点除外）；可达性告警误报（移到 runtime 用完整路由计算）。
- 验收：61 测试全绿（control_flow 10 + error_policy 4 + 既有 47）；`examples/graph.yaml`（switch→parallel+join→foreach→batch）与 `basic.yaml` 端到端正确；clippy 0 告警、fmt、文件/函数长度门禁全过。
- 后续：S3（`sohara-triggers`：http/cron/queue 事件总线 + `serve` 模式 + 优雅停机）。

## 14:40 CST — S3 实现：触发器 + serve 模式

- 变更：新增 `sohara-triggers` crate（`InProcessBus` 有界 topic 总线、`QueueSource`/`CronSource`/`HttpSource`，均实现 core 的 `Trigger` 生命周期 trait）；core 新增 `bus::EventBus` trait 与 `BuildContext.bus`；config 新增 `TriggerConfig`（trigger id 纳入边端点与 source 计数校验）；runtime 新增 `serve`/`serve_with_shutdown`（启动触发器→跑图→信号→停触发器→排水→flush）；builtins 新增 `queue` sink；CLI 新增 `serve` 子命令。

- 验收：67 测试全绿（新增 triggers 5 + serve 集成 1）；端到端 `sohara serve examples/serve.yaml`：webhook POST→202→记录落 log sink、cron 5s 触发、SIGTERM→"graceful shutdown requested"→打印统计→退出码 0。

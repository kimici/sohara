## 08:35:06 CST — D2 `sohara.flow.run(...)` 落地

- **变更**：实现 QuickJS 子 flow runtime。`sohara-core` 新增 `FlowRunner` 抽象，`BuildContext` / `StepEnv` 增加 flow runner 注入；`sohara-runtime` 新增 `RuntimeFlowRunner`，支持两种语义：无 trigger 的子 flow 在独立 OS 线程中同步执行完成；带 trigger 的子 flow 在独立 OS 线程 + tokio runtime 中启动，立即返回 stop handle，并可由 `handle.stop()` 停止。`sohara-js` 新增 `__flow_run` / `__flow_stop` / `__flow_save` 回调，`preamble.js` 的 `sohara.flow.run(config)` 已返回 `{ stop() }`。另外也顺手把 `sohara.sleep(整数)` 的 QuickJS 参数转换问题修掉，并补了 runtime cleanup：父脚本 invocation 结束时会自动 stop 尚未手动停止的子 flow。
- **原因**：继续推进 roadmap D2，使 JS 不仅能 build/save 整条 flow，还能在脚本内部直接运行子 flow。
- **验收**：`cargo test -p sohara-runtime --test flow_run_api`、`cargo test -p sohara-js --test host_core`、`cargo test -p sohara-js --test flow_api`、`cargo test -p sohara-runtime --test script_registration`、`cargo test -p sohara-runtime --test persistence`、`cargo test -p sohara-runtime --test stdio_extensions`、`cargo test -p sohara-cli`。
- **剩余**：relative path base 目前仍以 JSON flow 自身求值/运行路径为主；更完整的 async bridge、sub-flow timeout / restart policy、以及 D2 文档进一步细化仍可继续补。
